🔧 Integración Básica

Agrega estas líneas a tu HTML:

<!-- Incluir el widget de OVRA --> <script src="https://tudominio.com/ovra-widget.js"></script> <!-- Configuración opcional --> <script> window.ovraWidgetConfig = { apiUrl: 'http://167.99.143.136:8000', buttonColor: '#007bff', position: 'bottom-right' }; </script>
¡Eso es todo! El widget aparecerá automáticamente en la esquina inferior derecha de tu página.

⚙️ Opciones de Configuración

Opciones Disponibles:

apiUrl: 'https://api.ovra.ai' - URL de la API
buttonColor: '#000000' - Color del botón
position: 'bottom-right' | 'bottom-left' - Posición del widget
theme: 'light' | 'dark' - Tema del widget
title: 'Asistente Fiscal OVRA' - Título del widget
<script> window.ovraWidgetConfig = { apiUrl: 'https://api.ovra.ai', buttonColor: '#ff6b6b', position: 'bottom-left', theme: 'light', title: 'Mi Asistente Fiscal' }; </script>

🎯 WordPress Integration

Para WordPress, puedes añadir el código en:

  • Tema: En el archivo footer.php antes de </body>
  • Plugin: Usando un plugin como "Insert Headers and Footers"
  • Customizer: En la sección "HTML/CSS/JavaScript adicional"
