🤖 ARTISTING - Demo del Widget de Chat

Este es un ejemplo de cómo el widget de chat de ARTISTING se integra en cualquier sitio web. El widget permite a los usuarios hacer preguntas sobre impuestos y contabilidad después de proporcionar su email.

Características del widget:

  • ✅ Registro simple con email
  • ✅ Aceptación de política de privacidad y términos
  • ✅ Chat en tiempo real con IA especializada en fiscalidad española
  • ✅ Referencias legales en las respuestas
  • ✅ Sistema de feedback para mejorar las respuestas
  • ✅ Diseño responsive y moderno
  • ✅ Fácil integración en cualquier sitio web

🚀 Integración del Widget

Para integrar el widget en tu sitio web WordPress, simplemente añade este código:

<!-- Cargar React y el widget --> <script crossorigin src="https://unpkg.com/react@18/umd/react.production.min.js"></script> <script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.production.min.js"></script> <!-- Div donde se montará el widget --> <div id="ovra-chat-widget"></div> <!-- Script del widget --> <script> // Aquí iría el código compilado del widget // El widget se auto-inicializa al cargar </script>
Nota: El widget se mostrará como un botón flotante en la esquina inferior derecha. Los usuarios pueden hacer clic para abrir el chat.

📋 Flujo de Usuario

  1. Click en el widget: El usuario hace clic en el botón flotante
  2. Registro: Se solicita email y aceptación de términos
  3. Bienvenida: Se muestra un mensaje de bienvenida
  4. Chat: El usuario puede hacer preguntas sobre impuestos
  5. Respuestas: La IA responde con información especializada y referencias legales
  6. Feedback: El usuario puede valorar las respuestas

🔒 Privacidad y Datos

El widget cumple con las normativas de protección de datos:

  • Solo se requiere email para el registro
  • Aceptación explícita de políticas de privacidad
  • Todas las conversaciones se almacenan de forma segura
  • Los datos se utilizan para mejorar el servicio
